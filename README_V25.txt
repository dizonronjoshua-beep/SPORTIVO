SPORTIVO V25 — USER TRAINING REQUEST & COURT COACH ADD-ON

USER SIDE UPDATES
- Training Plan renamed to Training Request.
- Training Request now includes trainee personal details, emergency contact, and guardian details for minors.
- Sport selection filters coaches by sport.
- Coach cards include View Details and contact/social account links.
- Training Level: Beginner, Intermediate, Hard / Advanced.
- Training Goal is a dropdown with an Other option for a specific custom goal.
- Submitting a request notifies the selected Coach and sends the User a reminder to reach out through the Coach contact links.
- Coach Training Requests module shows applicant details and lets the selected Coach approve or reject the request.
- Coach approval changes the User role to Trainee, grants trainee modules, assigns/creates a training group, and creates starter sessions.

BOOK A COURT UPDATES
- User information appears above the booking form.
- Added Training Coach Add-on: Yes / No.
- Added session goal dropdown and custom Other goal.
- Optional preferred coach is filtered using the selected court/sport.

PROTOTYPE NOTE
This remains a browser prototype using localStorage/sessionStorage. Production notifications, secure accounts, persistence, and real multi-user approvals require a backend/database.
