SPORTIVO V37 - COACH INTERACTIVE SCHEDULE

COACH / MY SCHEDULE
- Added interactive monthly calendar.
- Clicking a calendar date displays only the coach's sessions for that selected date.
- Session cards show training group, sport, court, topic, level, status, and the actual list of assigned trainees.
- Added Sort dropdown: earliest time, latest time, group, and status.
- Coach can reschedule an active session's date, time, duration, and court.
- Rescheduling checks both court conflicts and coach schedule conflicts.
- Assigned trainees receive a schedule-change notification.
- Added + Add Session button.
- Coach can create a new session by choosing group, date, time, duration, court, and topic.
- New sessions also check court and coach conflicts and notify assigned trainees.
- Completed and cancelled sessions cannot be rescheduled.

PORTAL UI CONSISTENCY
- User, Trainee, and Coach continue to use the same shared SPORTIVO portal shell and shared portal.css design.
- Coach schedule-specific layout is isolated in coach-schedule.css and coach-schedule.js.
